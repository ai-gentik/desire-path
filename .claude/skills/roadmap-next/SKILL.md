# Roadmap Next

Help the user decide what to build next from the project roadmap.

## Steps

1. **Find the roadmap** — look for `ROADMAP.md` in the current project root
2. **Read it** — identify which items are done (checked), in-progress, or open
3. **Suggest 2-3 candidates** — prioritize by:
   - Items explicitly marked as next/upcoming
   - Quick wins (low effort, high impact)
   - Logical dependencies (unblocked items first)
4. **Let the user choose** — present options briefly, don't implement until confirmed
5. **Execute** — once confirmed, start the work

## Format for suggestions

```
Here are the next candidates from the roadmap:

1. **[Item name]** — [1 line why this is a good next step]
2. **[Item name]** — [1 line]
3. **[Item name]** — [1 line]

Which one should we tackle?
```

Keep suggestions focused — don't list every open item.
